KB Market Survey V155 — Khmer PNG + Map Data Fix
=================================================

Fixes
-----
1. Restores /api/map/data on Railway by adding the missing province,
   district, commune, and village fields to the SQLAlchemy model.
2. Adds safe startup migrations for those four columns. Existing data and
   existing Railway tables are preserved.
3. Uses Khmer OS System for Khmer report cells and installs the matching
   Debian font package. This keeps coeng clusters joined in PNG output,
   including the word គ្រប់.
4. Removes zero-width formatting characters before LibreOffice rendering.
