KB Market Survey V158 - Khmer PNG shaping fix
================================================

Purpose
-------
Ensure Khmer is preserved as one Unicode shaping run when an Excel report is
converted to PDF/PNG. The regression word គ្រប់ must remain exactly:

U+1782 U+17D2 U+179A U+1794 U+17CB

What changed
------------
1. NFC-normalizes every Khmer report cell before workbook save.
2. Removes ZWSP/ZWNJ/ZWJ/WORD-JOINER/BOM characters copied from mobile text.
3. Repairs invalid normal/NBSP spacing between COENG and a Khmer consonant.
4. Forces Noto Sans Khmer and removes Excel theme-font overrides.
5. Stops PNG generation instead of silently using a wrong fallback font.
6. Installs explicit HarfBuzz and FriBidi shaping libraries in Railway.
7. Adds an exact Unicode and workbook round-trip regression test.

Apply in Git Bash
-----------------
cd /d/Bot/Market_Survey_Git

unzip -o \
  /c/Users/User/Downloads/KB_Market_Survey_V158_KHMER_PNG_SHAPING_FIX.zip \
  -d .

python -m py_compile \
  app/reports/excel_report.py \
  app/services/render_service.py

python -m pytest tests/test_v158_khmer_png_shaping.py -q

git add \
  Dockerfile \
  app/reports/excel_report.py \
  app/services/render_service.py \
  tests/test_v158_khmer_png_shaping.py \
  V158_KHMER_PNG_SHAPING_FIX.txt

git commit -m "Fix Khmer PNG shaping"
git push origin main

Railway verification
--------------------
After the deployment becomes Active, generate a new report PNG. The deployment
log must contain a line similar to:

  Khmer PNG font: Noto Sans Khmer|/usr/share/fonts/...

Do not judge an old Telegram PNG because it is already rendered and cached.
Generate a fresh /report after deployment and zoom in on the stock text. It must
show គ្រប់ with the RO subscript correctly joined below the first consonant.

If the font is unavailable, V158 deliberately keeps the correct Excel file and
does not produce a malformed PNG. The Railway log then explains that Noto Sans
Khmer is required.
