V137 Kobo Report Type conditional visibility

- The first Kobo screen shows only Region, Dealer, and Report Type.
- Report Date, Group, Member, outlet details, GPS, Outlet Type, and submitter name appear only after GT or HORECA is selected.
- The product section, Ring Pull section, and Key Issues section remain hidden until Report Type is selected.
- GT shows GT and shared products.
- HORECA shows HORECA and shared products.
- CB LITE NCP remains an own/shared product for both GT and HORECA.
- Report Type, Region, Dealer, Report Date, and Outlet Type remain required.
- Pint own products retain only Sale Status, Movement Score, Stock Status, and BBE/Freshness.
- Existing report calculation and PNG behavior remain unchanged.
