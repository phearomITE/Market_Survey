KB Market Survey V70 - Manual submit alerts only

Behavior
--------
No automatic alerts run at 09:30 or 10:30.
Alerts are generated only when a user sends a command in Telegram.

Commands
--------
/alert_submit
  Shows both today's <10 list and today's <20 list.

/alert_submit 10
  Shows only today's dealers below 10 submissions.

/alert_submit 20
  Shows only today's dealers below 20 submissions.

/alert_submit 2026-07-25
  Shows both lists for the selected date.

/alert_submit 2026-07-25 10
  Shows one list for the selected date.

Apply in Git Bash
-----------------
cd /d/Bot/Market_Survey_Git

python /c/Users/User/Downloads/patch_v70_manual_submit_alerts.py

cp /c/Users/User/Downloads/test_v70_manual_submit_alerts.py \
  tests/test_v70_manual_submit_alerts.py

python -m py_compile \
  app/services/submission_alert_service.py \
  app/bot/handlers.py \
  app/bot/run_bot.py \
  app/core/config.py

python -m pytest -q tests/test_v70_manual_submit_alerts.py

git add \
  app/services/submission_alert_service.py \
  app/bot/handlers.py \
  app/bot/run_bot.py \
  app/core/config.py \
  .env.example \
  README.md \
  tests/test_v70_manual_submit_alerts.py

git commit -m "Use manual dealer submission alerts only"
git push origin main

Railway
-------
SUBMIT_ALERT_ENABLED can be deleted or set to false.
The code no longer creates a 09:30/10:30 scheduler.
