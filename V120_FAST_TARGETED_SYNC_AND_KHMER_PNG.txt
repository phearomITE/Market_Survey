KB Market Survey V120 - Fast Targeted Sync and Khmer PNG

Fix 1 - CA8 exists in Kobo but report said DB rows 0
- /report performs one server-filtered Kobo sync for the requested dealer/date.
- Kobo receives dealer and report-date query filters, so it does not download and
  process the entire asset for one dealer report.
- Only one sync attempt is allowed; the old second 180-second retry is removed.
- Existing synchronized database rows are still used immediately.
- Excel is sent before PNG and up to four Telegram commands can run concurrently.

Fix 2 - Khmer correct in Excel but separated in PNG
- Docker installs fonts-khmeros-core in addition to Noto fonts.
- Before PDF/PNG conversion, a temporary render-only workbook applies
  Noto Sans Khmer only to cells containing Khmer characters.
- The original Excel workbook is not modified.
- LibreOffice uses the headless svp backend and UTF-8 locale.
- Example គ្រប់ should remain correctly shaped instead of separating marks.

Also included
- Manual /alert_submit 10 and /alert_submit 20 command registration.
- No HORECA product, CB LITE NCP, Kobo XLSForm or report-template changes.
