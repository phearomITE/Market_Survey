KB Market Survey V63 - Fast Summary and Export

MAIN SPEED FIXES
1. Database migrations run once per container, not on every /summary, /export,
   /start, and 60-second Kobo sync.
2. /summary and /export load only lightweight submission columns instead of
   loading tens of thousands of product/competitor ORM rows.
3. Wide Kobo rows are indexed once per outlet. Field aliases no longer rebuild
   400-500-column lookup dictionaries for every product and field.
4. Bulk commands calculate only movement and availability, skipping BBE, stock,
   prices, Ring Pull, and other calculations they do not use.
5. /summary and /export share an in-memory dealer analytics cache for the same
   unchanged report date.
6. Repeating the same command reuses the generated Excel file when the database
   snapshot has not changed.
7. Bulk commands use the existing 60-second auto-sync snapshot immediately.
   They sync only when the requested date has no database rows.
