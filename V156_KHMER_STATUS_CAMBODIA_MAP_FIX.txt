KB Market Survey V156 - Khmer PNG, Status Export, and Cambodia Map Fix
=====================================================================

What this patch fixes
---------------------
1. Khmer PNG rendering
   - Installs Khmer OS System and Noto fonts in the Railway image.
   - Normalizes Khmer cell text to Unicode NFC.
   - Removes hidden zero-width characters that split joined Khmer clusters.
   - Removes Excel theme-font overrides and explicitly applies Khmer OS System.
   - Uses an isolated LibreOffice profile and verifies the font with fc-match.
   - Joined words such as គ្រប់ are kept as one shaped Khmer cluster.

2. Restores /export_status YYYY-MM-DD
   - Workbook columns: Date, Region, Dealer, Status.
   - Always lists all 65 official dealers from R1-R8.
   - Submitted Summary only when Outlet Name contains បូកសរុបរួម.
   - Normal outlet submissions do not count.
   - If a date has no matching summary rows, all 65 dealers are Missing Summary.

3. Restores the public movement map
   - Railway starts FastAPI/Uvicorn beside the Telegram polling bot.
   - /map and /api/map/data are available from the same Railway service.
   - Map data is restricted to Cambodia GPS bounds.
   - Numeric score markers, filters, mobile drawer, satellite/street layers,
     outlet details, key issue, and Navigate are retained.
   - Canvas markers and a smaller phone payload keep zoom/pan responsive.
   - Dashboard and outlet table are not included.
