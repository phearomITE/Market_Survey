V151 Summary Status Unicode Fix
================================

Cause
-----
Kobo can store invisible Unicode controls or non-ASCII spaces inside the
Khmer Outlet Name marker. The previous exact string comparison displayed
BTI6 as Missing Summary even though Kobo visibly showed បូកសរុបរួម.

Fixes
-----
- One shared Unicode-safe summary marker detector.
- /export_status YYYY-MM-DD restored and registered cumulatively.
- Status workbook columns: Date, Region, Dealer, Status.
- Summary Submitted rows are green; Missing Summary rows are red.
- /alert_submit supports both today and historical dates.
- BTI6-style hidden Unicode regression test included.
