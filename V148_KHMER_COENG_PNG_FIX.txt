V148 - Khmer coeng PNG shaping fix

Problem
-------
The XLSX stored the correct Khmer sequence for គ្រប់, but Railway's basic
LibreOffice PDF export could select the wrong complex-text-layout (CTL) font.
The generated PNG then displayed a detached form such as គ្ ប់.

Fix
---
1. Keep the workbook text unchanged.
2. Export the PDF through LibreOffice UNO on Linux/Railway.
3. Set CharFontNameComplex=Noto Sans Khmer and Khmer locale on used cells.
4. Build the PNG from that Khmer-safe PDF.
5. Keep the existing basic LibreOffice converter only as a logged fallback.

Deploy
------
unzip -o KB_Market_Survey_V148_KHMER_COENG_PNG_FIX.zip -d .

python -m py_compile \
  app/services/render_service.py \
  scripts/libreoffice_khmer_pdf.py

git add \
  Dockerfile \
  app/services/render_service.py \
  scripts/libreoffice_khmer_pdf.py \
  tests/test_v148_khmer_coeng_png.py \
  V148_KHMER_COENG_PNG_FIX.txt

git commit -m "Fix Khmer coeng shaping in PNG reports"
git push origin main

Expected Railway log when generating the report
------------------------------------------------
Khmer CTL PDF export active: font=Noto Sans Khmer

If the log says it is falling back to basic LibreOffice export, confirm that
the newly built container includes python3-uno and scripts/libreoffice_khmer_pdf.py.
