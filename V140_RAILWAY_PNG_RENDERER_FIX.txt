KB Market Survey V140 - Railway PNG Renderer Fix
================================================

WHAT WAS FIXED
--------------
1. LibreOffice now uses a unique private profile for every report conversion.
   This prevents profile-lock failures when reports run close together.
2. Railway forces LibreOffice's true headless SVP backend.
3. If LibreOffice still reports an X11/display error, the renderer retries
   automatically through Xvfb.
4. PyMuPDF rendering is memory-bounded. Poppler/pdftoppm is the PNG fallback.
5. /report sends the Excel file immediately, then creates and sends the PNG.
6. Telegram and Railway logs now show the exact renderer failure reason.
7. Example credential values were removed from .env.example.

RUN IN GIT BASH
---------------
Close Excel and LibreOffice first, then run:

cd /d/Bot/Market_Survey_Git

unzip -o \
  /c/Users/User/Downloads/Market_Survey_V140_RAILWAY_PNG_FIX.zip \
  -d .

python -m py_compile \
  app/services/render_service.py \
  app/services/report_service.py \
  app/bot/handlers.py \
  app/bot/run_bot.py \
  app/reports/excel_report.py \
  app/main.py

python -m unittest tests.test_v140_railway_png_renderer -v

git status --short

git add \
  Dockerfile \
  .env.example \
  app/services/render_service.py \
  app/bot/handlers.py \
  tests/test_v140_railway_png_renderer.py \
  V140_RAILWAY_PNG_RENDERER_FIX.txt

git commit -m "Fix Railway Excel report PNG rendering"

git push origin main

VERIFY AFTER RAILWAY DEPLOYS
----------------------------
Run:

/report CA7 GT 2026-08-01

Expected Telegram result:
1. Excel file is sent immediately.
2. PNG file is sent next.
3. Final message says: Completed CA7 GT 2026-08-01: Excel + PNG sent.

Expected Railway log:

PNG renderer PDF ready: Market_Improvement_CA7_2026-08-01.pdf
PNG renderer image ready: Market_Improvement_CA7_2026-08-01.png

Railway variables:

LIBREOFFICE_PATH=/usr/bin/libreoffice
PNG_RENDER_SCALE=4.0
PNG_MAX_WIDTH=6000
PNG_RENDER_TIMEOUT_SECONDS=45

The Dockerfile already supplies these defaults, so you normally do not need
to add them manually.
