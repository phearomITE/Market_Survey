KB MARKET SURVEY V144 - FAST KOBO + KHMER PNG FIX
=================================================

WHAT THIS PATCH FIXES
---------------------
1. /report reads only the requested Kobo date, then filters Dealer and GT/HORECA.
2. /summary GT, /summary HORECA, /raw_movement, /export and /report_today no longer run a full-history PostgreSQL sync first.
3. One date fetch is cached for 180 seconds and reused by commands for the same date.
4. /export movement_multi fetches independent dates in parallel.
5. /report sends Excel first and then creates one bounded PNG preview.
6. LibreOffice uses a private true-headless profile, Noto Sans Khmer and NFC-cleaned Khmer text.
7. /alert_submit 10 and /alert_submit 20 are restored as manual commands.
8. Automatic all-history Kobo sync is disabled so it cannot block Telegram reports.

IMPORTANT DATE EXAMPLE
----------------------
The screenshot shows MDK2 HORECA on 2026-08-01. Therefore use:

  /report MDK2 HORECA 2026-08-01

The command /report MDK2 HORECA 2026-07-30 correctly returns no data when Kobo
has no MDK2 HORECA submission on 2026-07-30.
