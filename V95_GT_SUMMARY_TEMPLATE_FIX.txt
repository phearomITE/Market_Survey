KB Market Survey V95 - GT Summary Template Fix
================================================

What this fixes
---------------
- /summary GT YYYY-MM-DD now loads the supplied GT Excel template.
- Preserves the exact Summary and Detail sheets, merged cells, colors, widths,
  row heights, freeze panes, tables, and headings from that template.
- Populates the movement comparison columns instead of generating the old
  simplified five-column workbook.
- Updates the Detail sheet with the selected date's GT outlet data.
- Uses the existing 70% mean + 30% median movement calculation.
- Correctly shows submitted, partial, no-submit, and region-total row colors.

Apply in Git Bash
-----------------
cd /d/Bot/Market_Survey_Git

unzip -o \
  /c/Users/User/Downloads/KB_Market_Survey_V95_GT_SUMMARY_TEMPLATE_FIX.zip \
  -d .

Validate
--------
python -m py_compile \
  app/core/config.py \
  app/reports/summary_report.py \
  app/services/report_service.py

git status

Commit and deploy
-----------------
git add \
  .env.example \
  app/core/config.py \
  app/reports/summary_report.py \
  app/services/report_service.py \
  templates/template_gt_summary.xlsx \
  tests/test_v92_export_commands_summary.py \
  V95_GT_SUMMARY_TEMPLATE_FIX.txt

git commit -m "Use uploaded workbook for GT summary"
git push origin main

Railway
-------
No new Railway variable is required because the template is included at:

templates/template_gt_summary.xlsx

Optional explicit variable:

GT_SUMMARY_TEMPLATE_PATH=templates/template_gt_summary.xlsx

After Railway is Active, test:

/summary GT 2026-07-25

Expected workbook
-----------------
- Sheet 1: Summary
- Sheet 2: Detail
- Summary row 4 includes movement bands and competitor columns.
- Summary row 8 includes Member, movement bands, Product Competitor, and
  Movement Lead.
- Detail includes the template's 12 columns and Open Map links.
