KB Market Survey V77 - Human Map, Admin Filters and Secure Edit
================================================================

Adds:
- Raw per-product ratings only; movement 0 is hidden from map/list/KPIs.
- Province, District and Commune filters.
- GPS reverse-geocoding cached into PostgreSQL in throttled batches.
- Village/place details in the outlet card.
- Satellite/Street basemap and administrative/place-label layer control.
- View Only in List behavior.
- Secure edit modal for Stock, Movement (0-10) and Key Issue.
- Separate viewer and editor tokens.
- Improved Dashboard filters and operational KPI cards.

Required Railway variables:
MAP_VIEWER_TOKEN=<read-only token>
MAP_EDITOR_TOKEN=<different private editor token>
REVERSE_GEOCODING_ENABLED=true
REVERSE_GEOCODING_BATCH_SIZE=50
REVERSE_GEOCODING_USER_AGENT=KBMarketSurvey/1.0-contact-your-email

The Telegram /map and /dashboard buttons use MAP_EDITOR_TOKEN when configured.
External shared users should receive only MAP_VIEWER_TOKEN.
