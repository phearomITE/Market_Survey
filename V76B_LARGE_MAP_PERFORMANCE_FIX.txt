KB Market Survey V76B - Large Map Performance Fix
===================================================

Problem:
The API returned every product rating and the browser created a marker/table
row for each one. With 4,127 Kobo submissions this could freeze Chrome and
Telegram WebView even though /api/map/data returned HTTP 200.

Fix:
- Exact filters, KPIs and charts still use all matching ratings.
- Map receives one lightweight Canvas marker per outlet (up to 2,000).
- Marker color uses the outlet's lowest product score, never an average.
- Product table receives the first 750 matching raw ratings.
- The list header shows displayed rows versus total matching ratings.

Apply:
unzip -o KB_Market_Survey_V76B_LARGE_MAP_PERFORMANCE_FIX.zip -d .

Validate:
python -m py_compile app/web/router.py

Commit:
git add app/web/router.py app/web/map.js tests/test_v76_kobo_map_dashboard.py V76B_LARGE_MAP_PERFORMANCE_FIX.txt
git commit -m "Prevent large movement map from freezing browsers"
git push origin main
