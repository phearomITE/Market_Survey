KB Market Survey V85 - Map/Dashboard Import Fix
================================================

Cause
-----
run_bot.py imported dashboard_cmd/map_cmd from handlers.py, but the V84
handlers file did not define them. Railway therefore restarted the container
before the bot and web server could start.

Fix
---
- Restores map_cmd and dashboard_cmd.
- Registers /map and /dashboard in run_bot.py.
- Mounts the existing map/dashboard web router in app/main.py.
- Restores PUBLIC_APP_URL and map token settings.
- Preserves the GT/HORECA commands and templates from V84.

Required Railway variables
--------------------------
PUBLIC_APP_URL=https://marketsurvey-production.up.railway.app
MAP_PUBLIC_VIEW_ENABLED=true
MAP_VIEWER_TOKEN=your_existing_viewer_token
MAP_EDITOR_TOKEN=your_existing_editor_token

Apply and deploy
----------------
cd /d/Bot/Market_Survey_Git

unzip -o \
  /c/Users/User/Downloads/KB_Market_Survey_V85_MAP_DASHBOARD_IMPORT_FIX.zip \
  -d .

python -m py_compile \
  app/core/config.py \
  app/bot/handlers.py \
  app/bot/run_bot.py \
  app/main.py \
  app/web/router.py

git add \
  app/core/config.py \
  app/bot/handlers.py \
  app/bot/run_bot.py \
  app/main.py \
  tests/test_v85_map_dashboard_handlers.py \
  V85_MAP_DASHBOARD_IMPORT_FIX.txt \
  .env.example

git commit -m "Restore map and dashboard bot commands"
git push origin main
