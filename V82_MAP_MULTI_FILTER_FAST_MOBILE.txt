KB Market Survey V82 - Map Multi-Filter and Fast Mobile

Changes
-------
- Removes the complete OUTLET & PRODUCT LIST section.
- Supports selecting multiple Regions, Dealers, Dates, Provinces, Districts,
  Communes, Categories, Products and Movement bands.
- Product choices depend on selected categories. Selecting Beer displays only
  Beer products, including correctly categorized competitor beer products.
- Adds translucent red, yellow and green map areas behind numbered movement
  markers.
- Hides the six KPI cards on phones.
- Mobile initial payload returns no table rows and at most 180 outlet markers.
- Product details are loaded only after a marker is tapped.
- Keeps /map, /dashboard, editing and /export movement_multi.

Apply
-----
unzip -o /c/Users/User/Downloads/KB_Market_Survey_V82_MAP_MULTI_FILTER_FAST_MOBILE.zip -d .

python -m py_compile app/web/router.py app/main.py

git add app/web tests/test_v82_map_multi_filter_performance.py V82_MAP_MULTI_FILTER_FAST_MOBILE.txt
git commit -m "Improve map filters and mobile performance"
git push origin main

After Railway becomes Active, refresh the map. On Android, close and reopen
the Telegram Mini App once so its WebView does not reuse the old JavaScript.
