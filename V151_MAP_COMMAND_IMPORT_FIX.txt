V151 MAP COMMAND IMPORT FIX

Problem
-------
Railway crashed because app/bot/run_bot.py imported map_cmd, but the deployed
app/bot/handlers.py was an older version without that function.

Fix
---
This patch deploys the matching pair:

  app/bot/handlers.py
  app/bot/run_bot.py

Apply from Git Bash
-------------------
cd /d/Bot/Market_Survey_Git

unzip -o \
  /c/Users/User/Downloads/KB_Market_Survey_V151_MAP_COMMAND_IMPORT_FIX.zip \
  -d .

python -m py_compile \
  app/bot/handlers.py \
  app/bot/run_bot.py

python -c "from app.bot.handlers import map_cmd; print('map_cmd OK:', callable(map_cmd))"

git add app/bot/handlers.py app/bot/run_bot.py V151_MAP_COMMAND_IMPORT_FIX.txt
git commit -m "Fix Telegram map command import"
git push origin main

Expected Railway startup
------------------------
The ImportError for map_cmd must disappear. The logs should show:

  Movement map web server starting on PORT=8080
  KB Market Survey Bot running...
  Uvicorn running on http://0.0.0.0:8080

MAP_VIEWER_TOKEN=YOUR_LONG_RANDOM_TOKEN
