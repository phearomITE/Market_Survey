V166 - retain submitted market issues and solutions in dealer reports.

The old aggregator used only the newest final-summary control row. V166 reads the latest non-empty answer independently for market issues and solutions, preferring summary control rows. A newer blank control row no longer erases earlier written text. If no control row contains that field, the latest written answer from the report's outlet submissions is used. Existing dealer/date/report-type filtering remains in force. Up to four written points per field are kept; no text is invented.

The Kobo parser now explicitly supports current group keys, Khmer labels and HTML-labelled exports. Group/note instructions are not treated as answers. Normalized mapping version is bumped so future syncs reparse corrected metadata. Mixed timezone timestamps cannot break summary selection.
