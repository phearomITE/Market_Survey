KB Market Survey V76 - Kobo Map and Dashboard
================================================

This overlay adds:
- /map Telegram Web App command
- /dashboard Telegram Web App command
- Open Map and Dashboard buttons on /start
- Secure browser links protected by MAP_VIEWER_TOKEN
- Responsive desktop and mobile map UI
- Raw per-product own and competitor movement ratings
- Region, dealer, report date, category, product and score filters
- Outlet/product list, key issue, stock status and Google Maps navigation
- Dashboard KPIs and Region/Dealer/Product charts
- Railway-safe FastAPI web server using PORT and asyncio

Railway variables:
PUBLIC_APP_URL=https://YOUR-SERVICE.up.railway.app
MAP_PUBLIC_VIEW_ENABLED=true
MAP_VIEWER_TOKEN=YOUR_NEW_64_CHARACTER_RANDOM_TOKEN

Apply from Git Bash:
cd /d/Bot/Market_Survey_Git
unzip -o /c/Users/User/Downloads/KB_Market_Survey_V76_KOBO_MAP_DASHBOARD.zip -d .

Validate:
python -m py_compile app/core/config.py app/main.py app/web/router.py app/bot/handlers.py app/bot/run_bot.py
python -m pytest tests/test_v76_kobo_map_dashboard.py -q

Commit:
git add app/core/config.py app/main.py app/web app/bot/handlers.py app/bot/run_bot.py tests/test_v76_kobo_map_dashboard.py V76_KOBO_MAP_DASHBOARD_DEPLOYMENT.txt
git commit -m "Add Kobo map and dashboard Telegram Mini Apps"
git push origin main
