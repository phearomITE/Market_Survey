KB Market Survey V154 - Flexible Final Summary + Localized Status
================================================================

Included fixes
--------------
1. /report and /export_status now use the same final-summary matcher.
2. Supports exact and related Outlet Name variants, including:
   - សរុបរួម
   - បូកសរុបរួម
   - សរុបចុងក្រោយ
   - # ចែ ម៉ៅ , បូកសរុបរួម
   - quoted, punctuated, spaced and zero-width-character variants
3. CA3-style final-summary rows populate:
   - ចំណុចដួល
   - Key Issues
   - INITIATIVE IDEA / SUGGESTION
4. /export_status YYYY-MM-DD is available and uses Khmer status labels:
   - បានធ្វើបូកសរុបរួម
   - មិនបានធ្វើបូកសរុបរួម
5. The General template contains the four No Compromise rules.
6. Generated report print/preview area now includes No Compromise rows 51-55.
