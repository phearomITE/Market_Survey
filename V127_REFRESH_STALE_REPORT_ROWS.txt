when the database result was empty, so it treated the stale 17 rows as complete.

- Reload PostgreSQL after the refresh.
- Keep one Kobo submission = one outlet visit.
- Subtract only the approved summary Outlet Name marker from Total Outlet Visit.
- Preserve the V125 no-background-sync and V126 bounded exact query behavior.
