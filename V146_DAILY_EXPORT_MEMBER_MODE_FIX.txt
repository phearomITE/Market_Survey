KB Market Survey V146 - Daily Export Member Mode Fix
=====================================================

Change
------
For /export YYYY-MM-DD, Summary_Data now writes one Member value per dealer:
the member number occurring most often across that dealer's submissions for
the selected report date.

Example
-------
CA1 values: 4, 6, 7, 5, 4, 4, 4, 4, 5, 4, 4, 4, 5, 5, 6
Final Member: 4

Rules
-----
- Blank/invalid Member values are ignored.
- The most frequent valid integer is selected.
- If two values have the same highest frequency, the lower number is used.
- The final value is written as a numeric Excel value, not a joined text list.
- The calculation is independent for each Region + Dealer on the requested
  report date.
